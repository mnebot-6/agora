# Notas de versión — 1.1.0 (versionCode 4)

Pegar en Play Console → Versión → **Detalles de la versión → Notas de la versión**
(es-ES). Máximo 500 caracteres por idioma.

## es-ES

```
Ahora eliges cómo se paga cada actividad:

• Sin pago: apuntarse es instantáneo, como siempre.
• Pago externo: pones el importe y explicas cómo pagar (por ejemplo, un Bizum).
  Agora no mueve el dinero; el admin marca —y ya puede desmarcar— quién ha pagado.
• Pago con Agora: se cobra por tarjeta al reservar.

Quien abre el enlace de una actividad ve el importe y cómo pagar antes de pedir plaza.
```

## en-US

```
You now choose how each activity is paid for:

• Free: joining is instant, same as before.
• External payment: set the amount and explain how to pay. Agora doesn't move the
  money; the admin marks —and can now unmark— who has paid.
• Agora payment: card payment when booking.

Anyone opening an activity link sees the price and how to pay before requesting a spot.
```

## Aviso para el formulario de Play

Nada nuevo que declarar: no cambian permisos, ni los datos que se recogen
(Data Safety), ni la clasificación de contenido. El pago con tarjeta vía Stripe
ya estaba declarado en la versión 1.0.2.
